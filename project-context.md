# Контекст проекта: Логистическое приложение

## 📌 Общая идея
Веб-приложение для курьерской доставки. Пользователи могут отслеживать статус своих посылок по трек-номеру, рассчитывать предварительную стоимость доставки через калькулятор стоимости (вводят город отправки и назначения, потом вводят размер посылки (выбирают из 5 предлложенных, потом вводят вес посылки, нажимают рассчитать и получают то, сколько будет стоить доставка, рядом с рассчитаной ценой появляется кнопка "создать заказ", после нажатия на нее вводятся оставшиеся данные, фио отправителя и получателя, их номера телефонов, и адреса пунктов выдачи заказов, кнопка создать заказ еще раз и заказ создается, человеку на экран выводиться накладная в виде таблице, и трек номер заказа)), также есть авторизация пользователей по номеру телефона, пользователь может смотреть историю своих заказов, и искать конкертный заказ по трек номеру.
